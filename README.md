# Movie Recommender System

A Machine Learning project that recommends similar movies using Content-Based Filtering and Cosine Similarity.

**Live App:** https://movie-recommender-system-gxcp47stkhtc3zx8s9fdig.streamlit.app

## Features

* Movie recommendations
* Content-based filtering
* Cosine similarity algorithm
* Streamlit web application

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit

## ML Concepts Used

* Data Preprocessing
* NLP (CountVectorizer)
* Feature Extraction
* Cosine Similarity
